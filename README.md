# 📊 Accenture India HR Analytics Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive **HR Analytics Dashboard for Accenture India**, developed using Microsoft Power BI. The dashboard provides insights into employee workforce distribution, attrition, retention, salary and compensation, performance ratings, promotions, and recruitment.

The project contains multiple dashboard pages designed to support HR analysis and data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze overall workforce distribution.
- Monitor employee attrition and retention.
- Understand salary and compensation trends.
- Analyze employee performance and promotions.
- Explore workforce distribution across departments and locations.
- Track recruitment stages and candidate sources.
- Build an interactive HR dashboard with KPIs and visualizations.
